# VeriCred Backend

Python FastAPI backend for the VeriCred on-chain verifiable credentials platform.

## Tech Stack

- Python
- FastAPI
- Web3.py
- IPFS
- Pydantic
- Uvicorn

## Responsibilities

The backend handles:

- Certificate metadata processing
- IPFS integration
- Blockchain data reading
- Certificate verification
- QR code generation
- Certificate PDF generation
- Issuer-related APIs
